Proyectos

Aquí puedes ver algunos de mis proyectos más recientes:

BMI Calculator

Esta aplicación permite calcular el Índice de Masa Corporal de una persona utilizando su nombre, edad, peso y estatura. La aplicación convierte automáticamente el peso de libras a kilogramos y la estatura de pulgadas a metros para realizar el cálculo correctamente. Además, evalúa el resultado y clasifica el estado físico del usuario según las categorías estándar: Underweight, Normal, Overweight u Obese. El propósisto de esta aplicación es calcular el BMI de un usuario de manera precisa

Hotel Room Selection

Esta aplicación permite al usuario seleccionar entre dos tipos de habitaciones de hotel: Standard Room y Deluxe Room. La interfaz muestra imágenes representativas de cada habitación y botones que permiten alternar entre ellas. Al seleccionar una opción, la aplicación muestra la imagen correspondiente y habilita el botón para confirmar la selección. Finalmente, el sistema muestra un mensaje indicando que la selección ha sido completada y permite cerrar la ventana. El propósisto de esta aplicación es simular un sistema básico de selección de habitaciones

Caleb Rotger Services

Esta aplicación permite calcular el pago de un empleado a partir de la información ingresada por el usuario. El sistema recopila datos como nombre, dirección, teléfono, número de dependientes y horas trabajadas. Luego procesa estos valores y genera resultados. El propósito de esta aplicación es automatizar el cálculo del pago de un empleado.

Sale Tax Calculator

Esta aplicación permite calcular el impuesto y el total a pagar basado en el precio de un producto y la tasa de impuesto ingresada por el usuario. El sistema recibe dos valores numéricos: el precio original y el porcentaje de impuesto. Luego, procesa estos datos para calcular el monto del impuesto y el total final. El propósito de esta aplicación es calcular de forma rápida y precisa el impuesto y el total a pagar por un producto.
